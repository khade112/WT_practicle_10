# 🏔️ Kalsubai Tourism

A full-stack tourism web application designed to provide
information about Kalsubai tourism and manage visitor bookings.

## 📌 Overview

Kalsubai Tourism is a web application developed to simplify
tourism information and booking management for visitors.

The application provides package details, booking functionality
and an administrative dashboard for managing bookings.

## ✨ Features

- 🏔️ Tourism information
- 📅 Visitor booking
- 👥 Number of visitors
- 💳 Payment options
- 🔐 Admin login
- 📋 Booking management
- ✏️ Edit bookings
- 🗑️ Delete bookings
- 📊 Booking count
- 🗄️ Database integration

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Node.js
- Express.js
- MongoDB
- Mongoose
